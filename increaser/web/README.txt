The Increaser — a live looper in the DAWters and Son suite. Free software (GPL-3.0-or-later).

Chrome or Edge: double-click index.html.
Safari, or if the microphone or audio won't start: run start-increaser.py (Python 3), which opens
http://localhost:8756. On a Mac you can also right-click it > Open With > Python Launcher.

Use headphones when monitoring a microphone. A USB foot switch is optional: learn it in the Pedal tab.
